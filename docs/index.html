How it works

  1. Capture

    Every notification, plus the SMS and call history you choose to import.

  2. Understand

    Rules tag each message instantly. Every 15 minutes, Qwen checks messages from people for anything you owe them.

  3. Learn

    Reply habits per person and a small urgency model trained on what you tap.

  4. Tell you

    The nightly digest, a home-screen widget and a quiet card on the lock screen.

Install

Recall isn't on the Play Store yet, so you install the APK file yourself. It takes a few minutes. Do it on the phone.

Recall isn't on the App Store. You install it with AltStore or SideStore, signed with your own Apple ID. Give it 15 minutes the first time.

iPhone apps can't read other apps' notifications, so Shortcuts hands your texts and emails to Recall instead. It sees what you route to it, not everything.

  1. Download the APK

    Tap Standard APK above. If Chrome warns that the file might be harmful, tap Download anyway.

  2. Install it

    Open the file from the download notification or the Files app. If Android asks, tap Settings, turn on Allow from this source, go back and tap Install.

    If Play Protect says the app is unknown, tap More details → Install anyway. It's unknown because it isn't on the Play Store.

  3. Open Recall and allow access

    Tap Get started, then turn on Allow notification access, Allow notifications and Allow exact timing. Allow SMS access is optional; it's how Money reads bank SMS.

    Is the notification access switch greyed out? Open Settings → Apps → Recall → ⋮ → Allow restricted settings, then come back.

  4. Give Recall a brain

    Pick the model Recall suggests for your phone and tap Download. It's 0.4 to 2.5 GB, so use Wi-Fi. You can skip this: capture, Waiting and Money work without it.

    Offline edition: open the Download link in your browser, then tap Import a .gguf file and pick the file.

  5. Keep it running

    Tap Allow background running, then set battery to Unrestricted. OnePlus, Xiaomi, Samsung, Oppo and Vivo close background apps otherwise, and the digest won't come.

  1. Set up AltStore or SideStore

    These install apps from outside the App Store with a free Apple ID. AltStore needs AltServer running on a Mac or PC. SideStore needs a computer only for its first setup. Follow their guide once.

  2. Turn on Developer Mode

    Open Settings → Privacy & Security → Developer Mode, turn it on and let the iPhone restart. Sideloaded apps won't open without it.

  3. Install Recall

    On the iPhone, tap iPhone IPA above and save it to Files. In AltStore or SideStore, open My Apps, tap + and pick Recall.ipa.

    A free Apple ID signs apps for 7 days. AltStore and SideStore refresh Recall in the background; open them now and then so it doesn't expire. Your data stays either way.

  4. Route your texts and emails

    Open Recall and go to You → Set up Shortcuts. In the Shortcuts app, make Message automations for texts containing debited and credited, one for the people you care about, and an Email automation. Each runs Add to Recall and is set to Run Immediately.

    Recall walks you through each one, with a box to paste a test message and see how it's read.

  5. Give Recall a brain

    You → Model. Qwen3 1.7B (1.1 GB) suits most iPhones; the 4B model is for iPhone 15 Pro and newer. Use Wi-Fi. Waiting and Money work without a model.

The notification access switch is greyed out

Android 13 and newer does this for apps installed from a file. Open Settings → Apps → Recall, tap ⋮ at the top right, then Allow restricted settings. Go back to Recall and try again.

"App not installed"

A Recall from somewhere else is already on the phone, signed differently. Uninstall it first, then install this one. Uninstalling deletes what it had stored.

The 9:30 PM digest didn't arrive

Your phone probably stopped Recall in the background. Set battery to Unrestricted (step 5) and make sure Allow exact timing is on.

Money is empty

Android 15 and newer hides most bank alerts from notification readers. Tap Allow SMS access in Recall so it reads bank SMS directly. They never leave the phone.

Updating to a new version

Download the new APK and install it over the old one. Everything Recall learned stays.

Why doesn't it read WhatsApp or Slack like on Android?

iOS doesn't let any app read another app's notifications. Texts and email come in through Shortcuts. For WhatsApp, export a chat (chat name → Export Chat → Without Media) and share it to Recall.

Recall won't open

Either Developer Mode is off, or the 7-day signature ran out. Open AltStore or SideStore and tap Refresh on Recall.

Nothing shows up in Recall

Check each automation in Shortcuts is set to Run Immediately and its Message is the Shortcut Input's Content. The test box in You → Set up Shortcuts shows whether Recall itself reads a message.

The digest has old news

iOS can't wake an app at an exact time, so Recall rewrites the 9:30 PM notification each time a message comes in or you open it. On a quiet day it may only say how many people are waiting.

Why not the App Store?

Publishing there needs a paid Apple developer account. The IPA is the free way to try it now.
